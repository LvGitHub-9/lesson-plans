## 教案的体例

每个知识点都按同一套 **11 字段**展开（完整说明见 [TEMPLATE.lesson.md](TEMPLATE.lesson.md)）：

| 字段 | 作用 |
|---|---|
| **原子性** | 只考一件事（否则拆开） |
| **原话** | 附章节号，**能指回原文** |
| **机制 / 为什么** | 材料没给就明确写「缺口」，**不编** |
| **前置** | 依赖哪个点（材料几乎不声明前置，需自己推） |
| **标准范例** | 能复算 / 能复现的最小例子 |
| **常见误解** | 明确列出来 |
| **适用边界** | 什么情况下不成立 |
| **预考题** | 学**之前**问的题（先测后学优于学完再测） |
| **练习题 + 答案** | 难度递增，答案可核对 |
| **迁移题** | 换一个情境 |
| **掌握判定** | 能说清 / 能应用 / 能回忆 |

**为什么这么做**：常见的"AI 总结课程"产物是**摘要**——读起来很顺，但没法用来学。
摘要不能自测，也就无法暴露"看着懂、合上书调不出来"的流畅性错觉。
把材料变成题，才有可能真的学会。

## 怎么用

1. **先看课程总纲**（`overview.lesson.md`）——里面有讲与讲的依赖、**跨讲概念线**、学习路径。
   一门课是螺旋上升的：同一个判据在多讲反复出现，按"讲次"学容易忘，按"概念线"串才记得住。
2. **进到某一讲**，先做**预考题**（不要先看讲解）。
3. 读「原话 + 机制」，做练习题，最后用**掌握判定**那三条自检。
4. 材料没说清的地方，看**缺口汇总**——那是显式标出的已知边界，不是遗漏。

## 加一份新教案

1. 复制 [`TEMPLATE.lesson.md`](TEMPLATE.lesson.md)，按 11 字段填
2. 建 `courses/<短名>[-<年份>]/`，放教案 + 一份该目录的 `README.md`
   （**含该材料自己的署名与许可**）
3. 更新根 `README.md` 的收录表、`NOTICE.md` 的署名表
4. 如果这门课/这本书超过一讲（一章），再加一份 `overview.lesson.md`（做法见模板末尾）

> **材料是书时**：许可通常是「保留所有权利」，所以**只能转述与短引用**，
> 不能太段转录；并在该目录的 `README.md` 里写明「本教案不能替代原书」。

**备课流程速查**（完整版在模板里）：

```
① 找文字源（讲义 / 课程站点 / 博客 / 教材）  ← 最高优先，命中即升级为 A 类材料
② 平台 AI 字幕                              ← 视频的「讲解」层
③ 本地 ASR + 领域术语表                     ← 第二份独立转写
④ 两份转写交叉验证 → 只保留术语级分歧
⑤ 抽帧读图                                  ← 只在 ①② 未覆盖时用
⑥ 切原子点 → 11 字段 → 教案
```

**三条纪律**（这是这个库和其他"课程笔记"的区别）：

1. **溯源**：每个点必须能指回章节号 / 页码 / 时间戳。指不回去的 = 自己编的。
2. **三分标记**：`【原话】` / `【外部补充】` / `【待查证】` 绝不混。
3. **缺口写「缺」**：材料没给机制、没给边界、没给答案，就明确写缺口。
   **宁可留白，也不要编一个像模像样的解释。**

## 分支约定

- `main` —— 已完成、已泛化的教案（可以直接读）
- `draft/<课程>` —— 备课中途的状态（未完成 / 未泛化），**不要指望能直接读**

> 多门课用**目录**组织，不用分支：分支之间无法一起浏览和搜索，且每门课都要重复公共文件。
