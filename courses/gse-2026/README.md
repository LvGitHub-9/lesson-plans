## 建议入口

- **看全局** → 总纲的 §3 **跨讲概念线**。课程是螺旋上升的：同一个判据在多讲反复出现。
  按讲次学容易忘，按概念线串才记得住。
- **看一个具体点** → [第 01 讲 §S15「修改的局部性」](01-welcome-to-the-future.lesson.md)，
  它与经典软件工程里的「改动放大 / 焦油坑」是同一个判据。

## 这门课的备课特点

- **材料是 A 类**：课程有官方讲义（9–15 节清晰结构），不是从字幕反推的。
  所以**主溯源锚点是讲义章节号，时间戳只是辅助**。
- **两份独立 ASR 交叉验证**：讲义有无覆盖的课堂讨论，靠双份转写互校定位，并标出分歧点。
- **崩溃修补**：6 讲里有 5 讲本地 ASR 出现循环崩溃，用另一份转写补回（详见各讲教案末的说明）。
- **预考题用了课堂上真实提的问题**（`【讲义原话·课堂提问】`）——比自编题更贴合课程设计者的意图。

## 教案面向的学习者设定

⚠️ 这套教案**不是通用的**，它面向一位 **C / 单片机 / 嵌入式背景**的学习者编写：

- **不假设面向对象前置** —— 第 05 讲的契约式设计（原为 Eiffel）**全量改写为 C**
- **未学过的领域概念一律展开** —— 第 06 讲涉及的数据库 / 编译原理 / DDD 概念逐项展开
- **英文术语给中文对照**
- **类比素材限定在**：信号与系统、电机控制 / FOC、嵌入式与硬件调试、C 工程实践、通信原理
- **避免使用的类比**：数据结构、AI / 机器学习、大型软件架构与设计模式

> 如果你来自不同背景：**判据与题目可以直接用，例子需要按自己的领域替换**。
> 这套"同一份材料如何适配不同读者"的做法，本身也是可复用的一部分。
